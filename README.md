# 🛒 BlinkIT Grocery Sales Dashboard

### Grocery Sales Analysis & Business Performance Insights

An Excel-based data analytics project that explores grocery sales performance across product categories, outlet types, and outlet locations using data analysis, PivotTables, charts, and KPI metrics.

---

## 📌 Project Overview

The **BlinkIT Grocery Sales Dashboard** transforms grocery sales data into meaningful business insights. It helps analyze sales performance, compare product categories, evaluate outlet performance, and understand sales variation.

## 🎯 Project Objectives

- Analyze total, average, and median sales.
- Compare sales performance across product categories.
- Evaluate average sales by outlet type.
- Compare average sales across outlet location types.
- Identify unusually high or low sales using the Interquartile Range (IQR) method.
- Present key metrics and comparisons in a visual dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- PivotTables and PivotCharts
- Excel formulas and statistical functions
- Data visualization
- IQR-based outlier analysis

## 📊 Key Performance Indicators (KPIs)

- Total Sales
- Average Sales
- Median Sales
- Sales Variation (Standard Deviation)

## 📈 Analysis Performed

### 1. Product Category Analysis
Compare average sales across item categories to identify stronger and weaker sales-performing categories.

### 2. Outlet Type Analysis
Evaluate average sales across different outlet types to understand differences in sales performance.

### 3. Outlet Location Analysis
Compare average sales across outlet location types to explore location-based differences.

### 4. Sales Variation and Outlier Analysis
Use quartiles, the Interquartile Range (IQR), and outlier limits to flag potentially unusual sales values.

## 📋 Dashboard Features

- KPI summary cards
- Sales comparison charts
- Product category performance analysis
- Outlet type and location comparisons
- Interactive filters, if configured in the workbook

## 💡 Business Value

This analysis can help identify sales patterns, compare outlet performance, and support data-driven retail decisions. The results describe the supplied dataset and should not automatically be interpreted as causal relationships.
